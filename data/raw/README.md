# Сырые данные

Сюда кладётся исходная выгрузка `amazon_sales_raw.csv` (42 675 строк, 21–30 августа 2025).
В репозиторий она не входит.

Без неё работает всё, кроме первого шага. Очищенные данные (`data/processed/`)
и промежуточный аудит качества (`reports/_quality.pkl`) уже лежат в репозитории,
поэтому анализ, графики и отчёт пересобираются командой

```bash
python scripts/02_analyze.py
```

Полный прогон с нуля (`python scripts/run_all.py`) требует этого файла.
